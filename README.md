CR7 WebOS - Stardance 2026
Hey! This is my project for Stardance 2026. I built a Cristiano Ronaldo-themed web OS with draggable windows and interactive apps.

What's Inside
📸 Ronaldo Photos: A gallery app with photos of Ronaldo's best moments.

🎵 CR7 Music: A music player with some goofy soundtracks you can listen to.

🏆 Career: A full page showing all of Ronaldo's career stats, goals, and trophies.

ℹ️ About: A simple info page explaining what the project is for.

🔥 Extra Features: You can drag any window around the screen, check the live clock on the top bar, or click the "SIUUU!" button to play the sound effect!

How I Made It
HTML for the structure of the desktop and windows.

CSS to make it look like a real dark-mode operating system.

JavaScript to handle double-clicking icons, moving windows around, and the sound effects.

How to Play Around With It
Open index.html in your browser.

Double click any icon on the desktop to open up that app.

Click and drag the top bar of any window to move it around your screen!
